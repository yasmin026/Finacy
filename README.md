# 💳 Financify — Dashboard de Controle Financeiro

> Uma aplicação web interativa para gestão e controlo financeiro pessoal, com suporte a gráficos comparativos por categoria, indicadores KPI e exportação de relatórios.

---

## 🚀 Funcionalidades

* **Painel de Indicadores (KPIs):** Visualização clara do saldo total, receitas e despesas acumuladas.
* **Gestão de Transações:** Adição e remoção de entradas e saídas com categorias personalizadas.
* **Gráficos Interativos (Chart.js):** Distribuição de despesas por categoria e evolução do saldo ao longo do tempo.
* **Filtros e Busca:** Pesquisa rápida de transações por descrição ou tipo.
* **Exportação de Dados:** Exportação do histórico de transações para formato CSV.
* **Persistência de Dados:** Salvamento automático de todas as movimentações via `localStorage`.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semantic**
* **Tailwind CSS** (design responsivo em *Dark Theme* com efeitos *Glassmorphism*)
* **JavaScript (ES6+)** (manipulação de DOM, cálculos e gestão de estado)
* **Chart.js** (renderização de gráficos de rosca e barras)
* **FontAwesome** (ícones modernos)
* **LocalStorage API**
